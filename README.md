# Makeup Store Management System (DBMS)

## Project Overview
The Makeup Store Management System is a database management project designed to manage the operations of a makeup business efficiently.

The system stores and manages product details, customer information, orders, order items, and supplier information using SQL.

## Technologies Used
- MySQL
- SQL
- phpMyAdmin
- XAMPP

## Database Entities
The database consists of five main tables:

1. **Products** – Stores makeup product information.
2. **Customers** – Stores customer details.
3. **Orders** – Stores customer order information.
4. **OrderItems** – Stores individual products included in each order.
5. **Suppliers** – Stores supplier information.

## Key Features
- Create and manage database tables.
- Insert, update, and delete records.
- Retrieve all or selected records.
- Filter records using WHERE and LIKE.
- Sort records using ORDER BY.
- Perform aggregate operations using COUNT, SUM, AVG, MAX, and MIN.
- Manage relationships using Primary Keys and Foreign Keys.

## How to Run the Project

1. Install XAMPP.
2. Start Apache and MySQL.
3. Open phpMyAdmin.
4. Create or select the database named `makeup`.
5. Go to the Import option.
6. Select the `makeup.sql` file.
7. Click Import/Go to execute the SQL file.
8. Explore the database tables and execute SQL queries.

## Project Files
